## 问题 1：素材显示黑屏

### 根因分析

从 Logcat 看到：
```
加载图片: mediaId=4, file=.../725e6b8a5aaf42a0a35eec63935f3a6e.png, exists=false
文件不存在: .../725e6b8a5aaf42a0a35eec63935f3a6e.png
```

文件下载后不显示，可能原因：
1. `SyncManager.doSync()` 中下载等待但 PlayerActivity 未收到通知
2. `downloadMedia()` 的 URL 构造有问题（baseUrl 硬编码 `10.0.2.2`）
3. `ImagePlayer.showCurrent()` 中 `mediaId` 类型不匹配（Int vs Long）

### 修复方案

**文件 1：`SyncManager.kt`**
- `getBaseUrl()` 从 ApiClient 获取，不要硬编码
- `downloadMedia()` 添加成功/失败日志
- 下载完成后 emit 通知 UI 刷新

**文件 2：`ImagePlayer.kt`**
- 添加图片加载结果日志
- 移除调试用的 BitmapFactory 代码，恢复 Coil 异步加载
- 添加 fallback：文件不存在时显示占位图

**文件 3：`PlayerActivity.kt`**
- `mediaPaths` 构建时确保路径正确

## 问题 4：看门狗功能未实现

### 当前状态
`PlayerService.kt` 中 `startWatchdog()` 被调用但未实现具体逻辑。

### 修复方案

**文件：`PlayerService.kt`**

实现看门狗：
```kotlin
private fun startWatchdog() {
    handler.postDelayed(object : Runnable {
        override fun run() {
            checkPlayerActivity()
            handler.postDelayed(this, CHECK_INTERVAL)
        }
    }, CHECK_INTERVAL)
}

private fun checkPlayerActivity() {
    val activity = playerActivity?.get()
    if (activity == null || activity.isFinishing || activity.isDestroyed) {
        restartPlayerActivity()
    }
}

private fun restartPlayerActivity() {
    val intent = Intent(this, PlayerActivity::class.java).apply {
        addFlags(Intent.FLAG_ACTIVITY_NEW_TASK or Intent.FLAG_ACTIVITY_CLEAR_TOP)
    }
    startActivity(intent)
}
```
