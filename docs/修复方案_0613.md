## 已修复问题详情

### 问题 1：服务器重启后 Android 401

**根因：** Server 重启后 `player_secret` 重新生成，旧 token 失效

**修复：** `SyncManager.kt` 新增 `reRegister()` 方法：
- 检测 401 时自动重新注册
- 最多重试 3 次，指数退避
- 成功后保存新 token 并重新同步

---

### 问题 2：前端截屏按钮

**根因：** 调用 `POST /displays/{id}/screenshot` 需要上传文件，前端没传

**修复：** `frontend/src/api/display.js` 改为调用 command 接口：
```javascript
screenshot(id) { return http.post('/displays/command', { command: 'screenshot', display_ids: [id] }) }
```

---

### 问题 4：Android 离线播放

**修复：** `SyncManager.kt` 新增缓存逻辑：
- `saveSyncCache()` — 成功同步后保存数据到 `last_sync.json`
- `loadSyncCache()` — 从本地加载缓存数据
- `tryOfflineFallback()` — 连接失败时加载缓存继续播放

---

### 问题 7：熄屏/唤醒（Root 实现）

**修复：** `RemoteControl.kt` 重写：
- 使用 `su -c input keyevent 26`（电源键）实现立即熄屏
- 使用 `su -c input keyevent 224`（唤醒键）实现立即唤醒
- Root 不可用时降级到旧方案（设置超时）
- 添加 `Settings.System.canWrite()` 检查

### 问题 13：删除设备后重新注册信息丢失（已修复）

**根因：** `register_display` 函数创建新设备时，漏掉了 `platform` 和 `ip_address` 字段

**修复：** 在创建 `DisplayModel` 时添加这两个字段：
```python
display = DisplayModel(
    ...
    platform=data.platform,
    ip_address=data.ip_address,
)
```

同时修复 MAC 地址去重分支，同样添加这两个字段的更新。
